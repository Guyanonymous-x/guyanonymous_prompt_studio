Guyanonymous' Prompt Studio v3.4

A fully offline prompt builder for wildcard text files. Point it at your wildcard folder, design prompts with a live nested preview, and export in bulk. No install, no account, and nothing is uploaded.

Launch the app Download the single file User guide
Use Microsoft Edge or Google Chrome on a computer for the full feature set (remembered folders and saving straight into folders). Your wildcard files never leave your machine: the page blocks every network request, and it can only read or write folders you choose.

What it does

  • Scans a folder of .txt wildcards and builds prompts from __filename__ tags
  • Live sample with nested wildcards that open up, re-roll, lock and choose-a-line
  • Reusable picks, weights and pick-several
  • Model profiles with a token gauge, plus prefix, suffix and negative prompt
  • Batch, sweep and all-combinations export as TXT, CSV or JSON
  • History, favourites, library health check, tabs, versions and projects

Good to know

  • The live page and a downloaded copy keep their own settings, history and remembered folders, because browsers store them per site.
  • The live page always runs the latest version. To keep a specific version, download it from the tags page.
  • See the changelog for every version.
