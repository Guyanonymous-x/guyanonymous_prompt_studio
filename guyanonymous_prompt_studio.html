Folders

  
Each kind of file has its own folder, remembered between sessions. Windows may ask you to re-allow access when you reopen the app. Browsers refuse a few top-level system folders (Documents, Downloads, Desktop itself); pick a subfolder inside them.

Syntax and shortcuts

  

    
__name__
Replaced by a random line from name.txt. Lines can contain more __wildcards__; these are resolved until none remain.

    
__folder/name__
A file inside a subfolder. A bare __name__ also works if that name is unique.

    
{a|b|c}
Inline random choice (turn on in Output options).

    
{2-3$$, $$a|b|c}
Pick 2 to 3 different options, joined with “, ” (any separator between the $$ pairs). With one wildcard, {2$$, $$__props__} picks different lines from that file.

    
${name=__a__ __b__}
Pick once and remember it as name. Prints nothing here. Can be placed anywhere in the template.

    
${name}
Print the remembered value. Every use shows the same text, and wildcard files can use it too.

    
__file$name__
Pick from file, remember it as name, and print it. A second __file$name__ repeats the same pick.

    
$$
A literal dollar sign when the variable syntax is on. A lone $ (as in $5) needs no escape.

    
3:: text
Weight, in wildcard files and inside {…} (turn on in Output options). 0:: switches an option off.

    
Model and length
Pick your model to see an estimated token gauge under “Exactly what gets saved”. Limits are editable starting points. Calibrate the counter with the number your own tool reports.

    
Prefix, suffix, negative
Added to every copy, save and export. Wildcards are allowed in them.

    
Batch formats
Text, CSV or JSON (with each prompt’s seed and the lines that were picked). Splitting writes several numbered files.

    
Sweep
Writes one prompt per line of one wildcard while the rest stays random.

    
Tabs and Versions
Several templates can be open at once. Versions are autosaved; Versions… restores or compares them.

    
History, Library, Projects
Restore past samples or keep favourites. Search every line, check the library for problems, see where a file is used. Save sets of tabs as projects.

    
Right-click a part
Re-roll it, lock it so Roll new sample keeps it, choose a specific line, or copy its text.

    
# comment
Lines beginning with # in a wildcard file are skipped (optional).

    
Seed
Same seed + same template = same sample. Editing text keeps the other choices stable. Click a coloured part to re-roll only that part.

Models and token limits

  
These are starting points, not guarantees. Limits marked “estimate” or “unverified” come from research notes and community reports, so test them in your own setup and edit them here. Your changes are kept separately from the originals, so you can always revert.

Versions of this template

  
Versions are saved automatically a short while after you stop typing, and when you save or close a tab. They are kept inside this browser only.

  

  






  
Projects

  
A project is a named set of open templates (with their prefix, suffix, negative prompt and model) plus your output settings. Wildcard and output folders are not part of a project.
